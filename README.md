## 🎯 3. 멀티모달 제약 사항 해결 전략

AI 멀티모달 제작 과정에서 빈번히 발생하는 한계점들을 아래와 같은 전략으로 적용하였습니다.

* **화풍/캐릭터 불일치 (Consistency):**
  - 키비주얼(제품, 인물) 두 개를 초기에 생성하여 이를 이미지 생성마다 이용.
  - [예시: Midjourney의 `--sref (Style Reference)` 기능을 활용하여 네온 톤의 시네마틱 화풍을 모든 씬에 고정 적용했습니다.]
* **해상도 및 비율 혼재:**
  - 처음 이미지 생성 단계 마다 비율 16:9 옵션을 선택
  - [예시: 처음부터 모든 이미지 생성 단계에서 `--ar 16:9` 옵션을 강제하여 비디오 변환 및 편집 시 잘림이나 왜곡 현상을 방지했습니다.]
* **크레딧/대기열 리스크 관리:**
  - 이미지 단계에서 스토리보드를 100% 확정 후 비디오 변환을 진행하여 실패 비용을 최소화.
  - 메인 도구 마비 시 사용할 대체 도구 파이프라인(`[대체 도구명]`)을 사전 준비.
